# Aybox 工具箱

> 一个轻量、实用的 Android 工具箱应用

---

## 📖 简介

**Aybox 工具箱** 是一款集成多种实用小工具的 Android 应用，使用Md3的风格创作的一款App

---

## ✨ 功能特性

### 🧰 内置工具

| 工具 | 说明 |
|------|------|
| 📅 课程表 | 支持周数切换、课程提醒、桌面小组件 |
| 📱 设备信息 | CPU、内存、屏幕、系统版本一览 |

### 🚀 核心亮点

- **简洁 UI** —— 基于 Jetpack Compose，Material 3 设计语言
- **离线可用** —— 大部分工具无需联网，保护隐私
- **轻量无广告** —— 安装包小，启动快
- **持续更新** —— 内置检查更新，第一时间获取新版本
- **深色模式** —— 自动跟随系统，护眼舒适

---

## 🛠️ 技术栈

- **语言**：Kotlin
- **UI**：Jetpack Compose + Material 3
- **架构**：MVVM
- **数据库**：Room
- **网络**：OkHttp
- **异步**：Kotlin Coroutines + Flow
- **最低支持**：Android 8.0（API 26）

## ❓ 常见问题

**Q：应用会不会收集我的隐私数据？**
A：不会。绝大多数工具完全离线运行，不请求任何网络权限（除检查更新外）。

**Q：为什么安装时提示"未知来源"？**
A：因为 APK 不是从应用商店安装的，Android 系统默认会拦截。在设置中允许即可。

**Q：支持 iOS 吗？**
A：目前仅支持 Android。

**Q：如何反馈问题或建议？**
A：欢迎在 [Issues](https://github.com/xiaoye122/Aybox/issues) 中提出。
